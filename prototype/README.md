# Bluetooth 연결 시험판

갤럭시 움직임으로 Windows 커서를 제어하는 개발용 시험판이다. 보안과 조작 품질은 아직 충분히 검증하지 않았으며 배포용 제품이 아니다.

Windows 앱은 BLE GATT 서비스를 광고하며 연결 요청을 승인한 기기의 센서 입력을 커서 이동으로 변환한다. 쓰기에 암호화와 인증을 요구한다. 사용자가 휴대폰에서 제어를 시작하고 PC에서 연결을 승인해야 하며 PC에서 중지할 수 있다. 승인하지 않은 기기와 연결 해제 시 동작은 아직 충분히 검증하지 않았다.

## 개발 환경

승인받아 프로젝트의 `.tools`에 Google Android 명령줄 도구 및 SDK, Eclipse Temurin JDK 17, Gradle 8.14.6, .NET SDK 10.0.403을 설치했다. 내려받은 파일은 각각 공식 체크섬과 비교했다. 기존 시스템 PATH는 수정하지 않았다. Android SDK 라이선스 확인 과정에서 sdkmanager가 제시한 8개 항목을 수락했다. .NET 첫 실행은 HTTPS 개발 인증서를 생성했으며, 신뢰하도록 별도 설정하지는 않았다.

한글 경로에서 Android Gradle 플러그인의 경로 검사가 실패하여 프로젝트를 임시 X: 드라이브로 매핑해 빌드했다. 다른 PC에서 X:가 이미 사용 중이면 다른 빈 드라이브나 ASCII 경로를 사용해야 한다. SDK XML 버전 경고와 일부 deprecated API 경고가 남아 있다.

## 현재 검증 상태

- Windows 빌드 성공. 화면에서 광고 상태 `Started / Success`를 확인했다.
- Android 디버그 APK 빌드와 `lintDebug` 성공. `testDebugUnitTest`는 테스트가 없어 실행된 테스트가 없다.
- 갤럭시를 USB ADB로 연결해 디버그 APK를 설치했다. 갤럭시 앱의 전송 성공 메시지와 Windows의 시험 신호 수신 화면을 확인했다. 재연결과 승인되지 않은 기기 차단은 미검증이다.
- 연결된 테스트 기기에서 Android 17, 자이로스코프와 회전 벡터 센서가 보고되는 것을 확인했다. 실제 조작 품질은 미검증이다.
- 디버그 APK는 개발용 서명으로 생성되며, 다른 사용자에게 배포할 수 있는 완성본이 아니다.
- 회전 속도 입력과 Windows 마우스 이동을 연결했다. 사용자는 상하좌우 이동과 감도가 적당하다고 확인했다. 부드러움과 다른 기기 호환성은 추가 검증이 필요하다.
- 터치 영역의 클릭과 세로 스크롤을 실제 갤럭시와 Windows에서 확인했다. 로컬 시험 페이지에서 클릭 횟수 증가와 스크롤 위치 0→100px을 관찰했다. 두 손가락 우클릭, 길게 누르기 드래그와 글자 입력은 아직 확인하지 않았다.
